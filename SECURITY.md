# Harbourline security policy

Harbourline handles private household financial information. Do not include
budget amounts, account details, passwords, authentication links or payment
details in a public GitHub issue.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository when it is
enabled. Include the affected URL or file, steps to reproduce and the impact.
Do not attach customer data. The project owner will acknowledge a report within
five business days and provide progress updates until it is resolved.

Before the paid beta opens, the project owner must enable private vulnerability
reporting in the repository's Security settings and publish a dedicated
Harbourline security contact in the customer Privacy Policy.

## Scope

Report issues involving account access, household isolation, billing access,
payment webhooks, customer data export or deletion, exposed credentials and
cross-site scripting. Do not test against customer accounts or interrupt the
service. Use an account and household that you control.

## Supported release

Security fixes are applied to the `main` branch and deployed through the normal
reviewed release process.
